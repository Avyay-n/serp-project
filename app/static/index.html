Model Context Protocol (MCP) Integration

VeriSerp AI includes a native FastMCP server and connects with SerpApi's hosted MCP endpoint. Add live search and fact-checking to Claude Desktop, Cursor, or VS Code!

Option 1: Official Hosted SerpApi MCP

Add directly to Claude Desktop (claude_desktop_config.json) or Cursor:

{
  "mcpServers": {
    "serpapi": {
      "type": "http",
      "url": "https://mcp.serpapi.com/YOUR_SERPAPI_API_KEY/mcp"
    }
  }
}

Option 2: VeriSerp AI Agent FastMCP Server

Run VeriSerp's autonomous multi-engine fact-checking agent locally over stdio:

{
  "mcpServers": {
    "veriserp": {
      "command": "uv",
      "args": ["run", "python", "-m", "app.mcp_server"],
      "env": {
        "SERPAPI_API_KEY": "YOUR_SERPAPI_API_KEY"
      }
    }
  }
}
